# 12th Economics 1-Mark Quiz Game

This project is a simple Android quiz app designed for 12th Standard Economics exam preparation.

## Features
- 30-second timer per question
- 1-mark objective quiz format
- Score, accuracy, percentage, and time tracking
- Student result summary screen
- Economics-themed app icon

## Build instructions
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build or run on an emulator/device.
4. For a debug APK:
   ```bash
   ./gradlew assembleDebug
   ```

## Result fields shown in the app
- Student
- Total Questions
- Correct
- Wrong Questions
- Wrong Attempts
- Skipped
- Score
- Percentage
- Accuracy
- Total Time
- Average Speed / question

## APK output path
- `app/build/outputs/apk/debug/app-debug.apk`
